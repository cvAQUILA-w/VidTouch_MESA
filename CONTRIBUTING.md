# Corrections and Reproducibility Reports

Please use the repository issue tracker for:

- annotation corrections, with the affected Fabric ID and field;
- protocol or implementation questions, with the exact config and command;
- reproducibility reports, with environment details and the relevant SHA-256;
- rights, privacy, or takedown requests concerning released material.

Do not post credentials, private contact details, or unpublished third-party
content. A correction is reviewed against the canonical source record before a
versioned update is made. Historical revisions remain visible through Git.
